# Olist 电商平台经营分析：SQL 阶段总结

## 1. 分析范围与整体思路

本阶段围绕 Olist 平台的经营表现、用户购买行为和用户体验开展 SQL 分析，主要包括：

- 平台经营：月度订单量、商品销售额、品类结构与销售排名。
- 履约与卖家：配送延迟率、配送时长、地区差异、卖家销售和评分表现。
- 用户行为：购买频次、复购、首次购买月份与后续购买。
- 用户体验：评分分布、低分品类和地区，以及配送时效、商品价格和运费与评分的关系。


## 2. 平台经营趋势

### 2.1 月度订单量与商品销售额

Notebook 当前按订单购买月份统计已送达订单及商品销售额。商品销售额以订单商品明细表中的 `price` 求和，**不包含运费**。

| 月份 | 已送达订单数 | 商品销售额 |
|---|---:|---:|
| 2017-01 | 913 | 111,798.36 |
| 2017-05 | 4,004 | 489,338.25 |
| 2017-08 | 4,797 | 554,699.70 |
| 2017-10 | 5,214 | 648,247.65 |
| 2017-11 | 8,475* | 987,765.37 |
| 2017-12 | 6,187 | 726,033.19 |
| 2018-01 | 8,037* | 924,645.00 |
| 2018-03 | 8,017* | 953,356.25 |
| 2018-05 | 7,810* | 977,544.69 |
| 2018-08 | 7,142* | 838,576.64 |

\* 上表中的订单数来自订单表与商品明细表连接后的 `COUNT(order_id)`，商品销售额的 `SUM(price)` 是商品明细层面的求和。

现有结果显示，商品销售额在 2017 年逐步上升，并在 2017 年 11 月达到约 98.78 万；2018 年 3—5 月也处于较高水平，2018 年 6—8 月有所回落。初步看，平台交易规模在增长后进入相对稳定阶段，但平台增长逐渐进入瓶颈。

## 3. 订单履约表现

### 3.1 整体与分月配送延迟

Notebook 对实际送达时间晚于预计送达时间的订单定义为延迟订单，整体延迟率输出为 **8.11%**。

分月结果中，延迟率较高的月份包括：

| 月份 | 延迟率 |
|---|---:|
| 2017-11 | 14.31% |
| 2018-02 | 15.99% |
| 2018-03 | 21.36% |
| 2018-05 | 8.24% |
| 2018-08 | 10.39% |

其中 2018 年 3 月达到 21.36%，值得进一步检查。但月度延迟率会受到订单量、配送距离、品类构成和预计送达日期设定等因素影响，不能仅凭单月比例直接归因。

按买家州统计，查询结果中延迟率较高的地区包括 AL（23.93%）、MA（19.67%）、PI（15.97%）、CE（15.32%）和 SE（15.22%）；SP 为 5.89%。

### 3.2 实际配送时长

当前查询使用 `julianday(order_delivered_customer_date) - julianday(order_purchase_timestamp)`，衡量从下单到实际送达的总耗时，而不是单纯的运输环节耗时。有效记录为 96,470 笔，包含下单、处理、运输等环节的总时长。

## 4. 用户购买行为与复购

### 4.1 用户购买频次

按 `customer_unique_id` 聚合，并仅统计 `order_status = 'delivered'` 的订单后，购买订单数分布为：

| 已送达订单数 | 用户数 |
|---:|---:|
| 1 | 90,557 |
| 2 | 2,573 |
| 3 | 181 |
| 4 | 28 |
| 5 | 9 |
| 6 | 5 |
| 7 | 3 |
| 9 | 1 |
| 15 | 1 |

总计 93,358 名有已送达订单的用户，其中 90,557 名只有一笔已送达订单，约占 **97.0%**。有至少两笔已送达订单的用户为 2,801 名，约占 **3.0%**。这表明在当前数据和口径下，用户购买以单次购买为主，复购用户比例较低。

后续可以按品类、首次购买月份和用户消费特征拆分，观察复购差异。

### 4.2 首次购买月份与后续购买

首次购买月份统计显示，用户规模从 2017 年逐渐增长，2017 年 11 月有 7,060 名首次购买用户；2018 年 1 月有 6,842 名，2018 年 3 月有 6,774 名。2018 年 6—8 月首次购买用户数在约 5,878—6,144 之间。

当前 cohort 查询的结果显示，2017 年首购 cohort 的“再次购买率”大致在 2%—4%之间，2018 年部分月份显示更低

## 5. 用户评分与体验

### 5.1 评分分布与整体低分率

评论评分分布如下：

| 评分 | 评论数 | 占比 |
|---:|---:|---:|
| 1 | 11,424 | 11.51% |
| 2 | 3,151 | 3.18% |
| 3 | 8,179 | 8.24% |
| 4 | 19,142 | 19.29% |
| 5 | 57,328 | 57.78% |

平台平均评分为 **4.09 分**；1—2 分低分评论率为 **14.69%**。5 分评论占比最高，但仍有约七分之一的评论属于低分，说明总体评分较高与局部体验问题可以同时存在。

### 5.2 低分品类

当前查询中，低分率较高的品类包括：

| 品类 | 低分率 |
|---|---:|
| security_and_services | 50.00% |
| fashion_male_clothing | 28.03% |
| office_furniture | 25.87% |
| diapers_and_hygiene | 25.64% |
| fixed_telephony | 25.28% |

低分率较低的品类包括 food_drink（7.86%）、flowers（6.06%）和 cds_dvds_musicals（0%）

### 5.3 州与卖家低分率

当前按卖家州汇总的低分率中，AC 为 100%、AM 为 66.67%，SP 为 16.58%。

### 5.4 配送时长与评分

按评分分组的查询结果为：

| 评分组 | 订单数 | 平均下单至送达时长 |
|---|---:|---:|
| 低分订单（1—2 分） | 12,310 | 20.20 天 |
| 高分订单（4—5 分） | 75,700 | 11.09 天 |

低分订单的平均下单至送达时长比高分订单长约 9.11 天。另一个查询显示，延迟订单平均评分为 **2.57 分**，准时订单平均评分为 **4.29 分**。两项结果都提示配送体验与评分之间存在明显关联。

### 5.5 商品价格、运费与评分

使用 `NTILE(10)` 将商品明细按单价分成 10 组后，各组平均评分约在 **3.98—4.08** 之间，没有呈现清晰的单调变化。按单件运费分组后，平均评分大致从低运费组的 4.08—4.17，变化到最高运费组的 3.91。高运费组评分略低的现象值得继续观察。

## 6. 当前阶段的综合结论

结合已执行的查询，当前可以提出以下几条**待进一步验证的发现**：

1. **交易规模经历了增长，随后趋于相对稳定。** 商品销售额在 2017 年增长明显，2018 年春季仍处于高位，但增长放缓。
2. **销售额集中在少数头部品类。** health_beauty、watches_gifts、bed_bath_table 等品类销售额较高，后续可以进一步结合销量、商品价格与低分率分析其经营表现。
3. **用户复购比例较低。** 在已送达订单口径下，约 3.0% 的用户拥有至少两笔已送达订单。
4. **配送时效与评分有较强的描述性关联。** 低分订单的平均下单至送达时长明显更长，延迟订单的平均评分也显著低于准时订单，值得作为后续分析重点。
5. **局部品类和卖家存在低分信号。** 但需要考虑低样本量、明细重复关联会放大比例波动的因素。
